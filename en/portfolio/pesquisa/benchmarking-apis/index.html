Research Project — Undergraduate Research (2025)

Benchmarking APIs across Different Programming Environments — A Financial System of Debits and Credits

Final report (PDF, in Portuguese)

Project data:

Institution Federal Institute of Education, Science and Technology of Santa Catarina (IFSC) — Lages Campus
Programme Undergraduate Research — Call no. 04/2024/PROPPI (rolling admission)
Coordination Leonardo Bravo Estácio
Student researchers {% include pessoa.html nome="Fabricio Iaronka de Souza" %} and {% include pessoa.html nome="Vinicius Souza Corbellini" %}
Period July to December 2025
Keywords Software Benchmarking; API Performance; RESTful APIs; Load Testing; System Scalability

Summary:

Implement a functionally equivalent RESTful API in several languages, following the same specification and the same architecture. Each variant ran on two instances, behind a load balancer using round-robin and over a shared PostgreSQL database, with identical CPU and memory limits, so that operating conditions stayed uniform. Load tests with a high volume of concurrent requests were run on that environment and repeated to ensure statistical validity, measuring latency, error rate, data consistency and CPU and memory usage. The goal is to produce empirical evidence to support the choice of languages and technologies when building scalable, efficient and resilient APIs.

Results:

Four equivalent implementations of the API were delivered (Java/GraalVM/Quarkus, JavaScript/Node/Fastify, Python/Uvicorn/FastAPI and Rust/Tokio/Axum), running on two instances balanced by Nginx over the same relational database. The test campaigns, run with Gatling in warm-up, steady-state and cool-down phases, produced series of latency (p50, p95 and p99), throughput, error rate and resource usage, analysed with non-parametric tests and bootstrap confidence intervals. The results show that persistent connections, prepared statements and a well-tuned connection pool reduce tail latency and variability under pressure, and that the transport format and serialisation can shift p95 and p99 substantially even with the database and the mix of operations held constant.

Dissemination:

The work was presented as a video and a poster at the 7th “3 Minutes of Science and Technology” Showcase, part of the 22nd National Science and Technology Week, held by IFSC (Lages and Urupema campuses), on 4 November 2025.
